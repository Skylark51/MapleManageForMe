# MapleScouter optimizer recheck — 2026-08-22

## 10회 재확인 관점
1. 캐릭터명 검색 후 API 데이터가 분석 화면 전체의 기준값이 된다.
2. 보스세팅 최적화는 하이퍼/링크/유니온/보약을 `기존`과 `최적`으로 분리한다.
3. 보스 방어율을 별도 입력값으로 받아 방무 가치를 상황별로 바꾼다.
4. 크확, 크뎀, 방무, 데미지, 보공, 공/마를 동일 자원 안에서 경쟁시킨다.
5. 유니온은 현재 칸수를 자원으로 취급해 재배분한다.
6. 최적화 결과는 단순 추천 문장이 아니라 전/후 배분을 보여준다.
7. 스펙업 순서는 아이템/추가 스펙의 변화량과 비용을 분리해 비교한다.
8. 보스컷은 직업/보스 상성 때문에 절대값으로 과신하지 않도록 안내한다.
9. 보스 이미지는 보상 아이콘이 아니라 보스 자체가 식별되는 전용 portrait를 사용한다.
10. 캐릭터정보 → 분석&최적화 → 스펙업 순서가 하나의 흐름으로 연결된다.

## 공개 캐릭터 sanity check
MapleScouter 공개 검색 결과에서 `으낭다`를 조회해 실제 데이터가 채워지는 흐름을 확인했다.
- Lv.250 아델
- 전투력: 856,463,177
- 보스 300 일반 지표: 118,569
- 보스 380 일반 지표: 119,102

이 수치를 MapleManageForMe에 복제하지 않는다. 목적은 `캐릭터명 → 현재 API 상태 → 계산 입력값 자동 채움`이라는 동작을 검증하는 것이다.

## MapleManageForMe 구현 원칙
- MapleScouter의 비공개 환산 공식을 복제하지 않는다.
- NEXON API에서 받은 현재 최종 스탯을 기준으로 한다.
- 하이퍼 스탯은 공식 레벨별 비용과 상승치를 사용한다.
- 현재 하이퍼에 사용된 포인트와 잔여 포인트를 같은 예산으로 두고 재분배한다.
- 유니온은 현재 점령 효과를 칸으로 역산하고 동일 칸수 안에서 재분배한다.
- 크확은 100%에서 상한 처리한다.
- 방무는 단순 덧셈이 아니라 곱연산으로 처리하고 300/380% 방어율을 별도로 계산한다.
- 각 다음 하이퍼 레벨 또는 유니온 1칸의 `상대 화력 증가량 / 자원 소모`를 계산해 가장 효율적인 항목을 반복 선택한다.
- 결과는 `현재 → 계산 추천`으로 표시한다.
- 결과의 상승률은 MapleManageForMe 내부 비교 지표이며 실제 최종뎀이라고 표시하지 않는다.
